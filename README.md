# Sports Leaderboard

A live, multi-sport leaderboard for school intramurals, campus events and leagues. Colleges and teams compete across many sports, and standings update in real time on phones and desktops.

## Features

- **Any sport.** Head-to-head sports such as basketball, volleyball, football and chess, and ranked events such as athletics and swimming.
- **Flexible scoring.** Each sport sets its own points for a win, draw or loss, or its own points for each finishing place.
- **Overall standings.** A medal table ranks colleges across all sports, with gold, silver and bronze for each sport's top three.
- **Live updates.** Scores appear for everyone as soon as they're entered.
- **Multiple competitions.** Run intramurals, leagues and tournaments side by side.
- **Mobile friendly.** Works in any modern browser on phones, tablets and desktops.

## Roles

| Role | Access |
| --- | --- |
| Student | View standings and results |
| Sports coordinator | Enter match scores and event winners |
| Administrator | Manage competitions, teams, sports and user roles |

New users sign up as students. Administrators assign coordinator and admin roles.
